Graduate research briefing · one paired dimension-5 run · seed 0

Driving down uncovered surrogate volume on the 5D Rosenbrock problem

This report compares three acquisition strategies in an aggressive iterative experiment. Each method starts from the same 5,000-point design, repeatedly refits the same surrogate, and appends every candidate classified as uncovered. The question is simple: which strategy reaches Pout ≤ 2% with the least accumulated training data?

Result. Uniform-gap is the only method to reach the 2% target. It reaches 1.975% at checkpoint 5 with 491,092 training rows. Gaussian cloud and normalized shell continue to checkpoint 8 with more than one million rows and finish at 2.995% and 3.115%, respectively.

1. Sampling strategies

Every method uses the current surrogate's union of trust ellipsoids, denoted by \(\widehat{\mathcal G}=\bigcup_k\mathcal G_k\), to decide whether a candidate is already covered. The methods differ only in where raw candidates originate before this common coverage filter.

Uniform gap

Draw globally from the bounded box. Keep candidates outside the current ellipsoid union. This samples the objective's remaining uncovered set directly.

Normalized shell

Choose a random direction around each cluster, discard its random length, then place the candidate on one controlled shell outside that cluster.

Gaussian cloud

Keep both the random direction and the random Gaussian length. Candidates form a cloud with some points near a cluster and others far outside it.

Candidate formulas

Let \(T_k=U_k\Lambda_kU_k^T\) be the trust matrix for cluster \(k\), with center \(\mu_k\). In all cases, the implementation subsequently removes candidates classified inside the approximate union \(\widehat{\mathcal G}\).

\[C_{\mathrm{gap}}\sim\operatorname{Uniform}([-2,3]^5),\qquad A=\{x\in C_{\mathrm{gap}}:x\notin\widehat{\mathcal G}\}.\]
\[x_{\mathrm{shell}}=\mu_k+\gamma U_k\Lambda_k^{-1/2}\frac{z}{\lVert z\rVert},\qquad x_{\mathrm{cloud}}=\mu_k+\gamma U_k\Lambda_k^{-1/2}z,\qquad z\sim\mathcal N(0,I),\quad\gamma=1.5.\]

The shell has a fixed ellipsoidal radius \(q=1.5\). The cloud has \(q=1.5\lVert z\rVert\), whose typical size grows with dimension. This is why Gaussian proposals are rejected outside the bounded domain more often.

Candidate schedule200 candidates per cluster initially. After 10,000 clusters, this decreases as \(\max(10,\lfloor 200\times10{,}000/N_c\rfloor)\).
Acquisition policyAppend every retained candidate. No fixed batch size and no cap on retained points.

Measured coverage statistic

\[P_{\mathrm{out}}=\frac{1}{20{,}000}\sum_{i=1}^{20{,}000}\mathbf 1\{x_i\notin\widehat{\mathcal G}\}.\]

\(P_{\mathrm{out}}\) estimates the fraction of the test distribution outside the current learned trust-region union. It measures geometric coverage. It does not by itself establish a pointwise surrogate-error guarantee inside that union.

4. Training growth and acquisition volume

Every retained proposal is evaluated with the Rosenbrock function and enters all later fits. The number of appended rows therefore depends on the method and on the current learned union. Uniform-gap reaches the target after five fits with less than half the final training size of the shell arm.

6. Conclusions and limits

  1. Uniform-gap wins this paired race. It reaches 1.975% uncovered test volume. The other methods do not reach 2% within eight checkpoints.
  2. Local candidate volume is not enough. Shell retains 1.23 million points, the largest training array, yet finishes with the largest \(P_{\mathrm{out}}\). Candidate placement relative to global gaps is the controlling factor here.
  3. Shell normalization improves feasibility but not this objective. It reduces out-of-domain waste relative to Gaussian cloud, 9.09% versus 24.15%, but remains a local boundary sampler.
  4. The result is a single paired run. One seed supports a controlled comparison, not a confidence interval or a general ranking. Repeat the race across seeds and audit the \(k=10\) membership approximation before making a stronger claim.
